# UC8179 Lut波形更新脚本

# 1. 加载VCOM波形 (lutc), 42字节
CMD 0x20
SEND_LUT_DATA_CHUNK 0 42

# 2. 加载White to White波形 (lutbb), 42字节
CMD 0x24
SEND_LUT_DATA_CHUNK 42 84

# 3. 加载Black to White波形 (lutbw), 42字节
CMD 0x23
SEND_LUT_DATA_CHUNK 84 126

# 4. 加载White to Black波形 (lutwb), 42字节
CMD 0x22
SEND_LUT_DATA_CHUNK 126 168

# 5. 加载Black to Black波形 (lutww), 42字节
CMD 0x21
SEND_LUT_DATA_CHUNK 168 210
