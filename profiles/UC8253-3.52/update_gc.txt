# UC8251D 全局刷新脚本 (新增延时诊断版)

# 1. 启用窗口模式
#CMD 0x91
#WAIT_BUSY
#CMD 0x90
#DATA 0x00 0x7F
#DATA 0x00 0xF9
#DATA 0x01
#WAIT_BUSY

# 2. 发送“写RAM”指令
CMD 0x13

# 3. 数据注入点
SEND_IMAGE_DATA

# 4. 关闭窗口模式
CMD 0x92
WAIT_BUSY

# 5. 触发屏幕物理刷新
CMD 0x04 # Power On
WAIT_BUSY

CMD 0x12 # Display Refresh
DELAY 100 # <--- 在这里增加一个100毫秒的延时
WAIT_BUSY # 然后再检查忙状态

CMD 0x02 # Power Off
WAIT_BUSY
